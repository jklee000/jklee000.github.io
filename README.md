# 🧳💊 여행 상비약 가이드 (Travel Med Kit)

여행지 환경·동반자·증상·여행 월을 선택하면 꼭 챙길 **상비약 체크리스트**와 **복약 주의사항**을 한눈에 보여주는 웹 앱입니다. 접속 시 캐리어가 열리는 오프닝 애니메이션과 함께 시작됩니다.

## 🌐 데모 (GitHub Pages)

배포되면 아래 주소에서 볼 수 있습니다:

**https://jklee000.github.io/**

## ✨ 기능

- 여행지 유형 / 국가·세부지역 / 여행 월 / 동반자 / 증상 선택
- 조건에 맞는 **필수 · 상황별 선택 상비약** 자동 추천
- 성분별 복약 가이드, 주의·금기, 동반자별 주의, 현지 언어 성분명, 약국 요청 문구
- 인쇄 / PDF 저장, 이미지 저장
- 캐리어 테마 UI · 접이식 선택 목록 · 모바일 대응

## 🗂️ 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 웹 앱 본체 (단일 파일, Tailwind CDN) |
| `travel_meds.py` | 동일 로직의 CLI(터미널) 버전 |
| `meds.json`, `destinations.json` | CLI용 데이터 |
